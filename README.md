## Project Overview
This project tackles a multiple-choice question answering and ranking task. Given a question prompt and five answer choices (A–E), the goal is to predict the top 3 most probable correct answers, ranked by confidence.

The approach explores multiple modeling strategies, including:
- A model built from scratch
- A pretrained transformer-based model
- Retrieval-Augmented Generation (RAG) for context-aware reasoning
- Fine-tuning (LoRA) for improved task-specific performance
